# Orsino 個人入口網站

這是一個以 GitHub Pages 為目標的純靜態個人入口網站，主題聚焦在 AI、資訊與教學；目前採用朱紅鎏金的新春視覺風格。

## 本機預覽

直接開啟 `index.html` 即可預覽，也可以使用任意靜態伺服器：

```bash
python3 -m http.server 8000
```

接著開啟 `http://localhost:8000`。

## 上線前調整

- 將 `index.html` 內的 GitHub、YouTube、Threads 連結換成你的實際帳號。
- 將 `hello@orsino.dev` 換成你的主要聯絡信箱。
- 將此 repository 的 GitHub Pages Source 設定為 `main` branch 的 root 目錄。
